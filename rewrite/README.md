# Paper build package

This directory contains the LaTeX source for the 38-page main paper and 27-page online appendix, publication assets, build/verification scripts, and external provenance ledgers.

## Entry points

- `main.tex` — main job market paper
- `online_appendix.tex` — standalone Appendices A--E
- `build.ps1` — compiles both documents, combines them, mirrors stable output names, and renders every page
- `verify_pdfs.py` — checks metadata, page integrity, labels, logs, bibliography count, appendix scope, and forbidden production language

## Evidence boundary

Core yield-curve and currency results are reported from the 94-page source paper because the original analytical panel and estimation code are absent. Reused figures and transcribed values are mapped externally in `notes/copied_material_ledger.*`; section moves and deletions are mapped in `notes/original_to_rewrite_transformation_ledger.*`; equation changes are mapped in `notes/equation_provenance_ledger.*`.

Public delivered-easing and country-combination checks are generated by `research_pipeline/`. The current-vintage public 10-year-minus-3-month exercise is an adverse sensitivity test, not validation of the unavailable predictive inversion state.

The root reproduction workflow runs `research_pipeline/src/render_v03_public_tables.py` before compilation. That renderer converts machine-readable public-proxy outputs into `generated/tables/v03_*.tex`, mirrors the public specification-curve figure, and adds SHA-256 records for those paper-facing files to `research_pipeline/outputs/v03/yield_proxy/run_manifest.json`. The active LaTeX sections include the generated tables directly with `\input`.

Original Appendices F and G and the synthetic path-dependence exercise are not input by either reader-facing entry point.

## Build

From this directory:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

The script resolves MiKTeX, BibTeX, Poppler, and Python from `PATH`, environment variables, or explicit path arguments. It writes the 38-page main paper, 27-page appendix, and 65-page combined edition under `../output/pdf/`. The repository-root `run_reproduction.ps1` is the supported complete workflow and also copies the combined edition to `../Alt_JMP_v0.3.pdf`.
